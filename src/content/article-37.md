# 洛阳钼业 vs 紫金矿业 · 三大曲线 · 量价基本面 · 短中长期空间测算（2026-08-05）

> 数据口径：Tushare 量价/估值/财务（截至 2026-08-05 收盘）+ 公司公告预告 + 券商研报 + 公开新闻交叉验证。本文为研究支持用途，不构成买卖指令。

## 〇 一句话结论

> 两只票**基本面都在加速、估值却被打到周期下沿**——这一轮 1 月高点以来的回调是「杀估值」（PE 从 26x 砍到 10-15x），不是「杀业绩」（业绩反而翻倍兑现）。8/5 放量站上全部均线，是**周期叙事 + 风格切换回归**的右侧启动信号。**紫金是更稳的「金铜锂全能龙头」（forward PE 10.8x、ROE 33%），洛钼是更纯的「铜钴铌高弹性」（forward PE 12.8x、铜毛利占六成）**。中性看都有 ~25% 空间到一致目标价，乐观看紫金 40-60%、洛钼 30%；但**前提是铜金维持高位 + 加息预期别复活**。

## 二、量价基本面现状：为什么 8/5 大涨

**驱动力（多源交叉）**：

1. **商品端**：LME 铜现货 ~$14,300-14,600/吨（$6.6/磅）、沪铜 ~10.4 万元/吨，6 月刚创 $6.67/磅历史纪录；金价 ~$4,094/盎司。铜金同步高位。
2. **宏观端**：6 月美国 CPI 超预期走低，**「加息交易」基本解除**——这是压制有色半年的核心利空，现在消失。
3. **资金/风格端**：华创喊「**有色进入右侧交易**」；公募对有色持仓降至**近 3 年低位（1.98%）**，继续减持空间极小；而科创 50（H1 +64%）7 月两天跌 10%，**科技抱团松动、资金溢出到低估值有色**。
4. **业绩端**：2026 中报预告全部超预期（见下）。

**业绩兑现（公告预告，Tushare 已核对一致）**：

| | 洛阳钼业 | 紫金矿业 |
|---|---|---|
| 2025 全年归母 | 203.4 亿（+50.3%） | 517.78 亿（+61.55%） |
| 2026H1 预告归母 | **155-165 亿（+79~90%）** | **391 亿（+68%）** |
| 2026Q1 归母 | 77.6 亿 | 200.8 亿 |
| 2026Q1 净利率 | 13.3% | **25.5%（毛利率 36.3%！）** |
| 2025 ROE | 26.5% | **33.0%** |

紫金净利率（25.5%）几乎是洛钼（13.3%）的两倍——**核心差就是黄金**：紫金金业务毛利占 40.9%、铜占 34.5%；洛钼更纯，**铜毛利占六成以上**，是三家里最纯粹的铜弹性。

## 三、基本面驱动：商品 + 产能 + 成长性

### 商品价格（8 月初）

- **铜**：历史高位区间，结构性短缺（2026 全球缺口预期 15-33 万吨），AI 数据中心 + 新能源 + 电网三重拉动；摩根大通看 $12,500、花旗看 $15,000。
- **金**：$4,094，从 $5,626 回调；高盛目标 $5,400，摩根大通/瑞银 $6,200-6,300。央行购金 + 去美元化长牛未改。
- **钼**：钼精矿 5,175 元/吨度（YTD +34%），AI 算力新逻辑（SK 海力士 375 层 NAND 用钼代钨做字线）。
- **钨**：APT 均价上半年同比 **+360%**，曾破百万/标吨。
- **铌**：寡头稳价（CBMM 占 75%），2025 铌铁 $48.68/kg 微涨，洛钼铌毛利 44%，**全球第二、现金奶牛**。
- **钴**：~43 万/吨，刚果金出口配额制，从过剩转「刚性缺」。

### 产能成长性（2026 → 2028）

| | 洛阳钼业 | 紫金矿业 |
|---|---|---|
| 铜 | 74.1 万吨 → 80-100 万吨（KFM 二期 2027、TFM 三期） | 109 → 120 → **150-160 万吨**（巨龙二期、卡莫阿） |
| 金 | 新增 6-8 吨（巴西并表），2029 奥丁投产后 20 吨 | 90 → 105 → **130-140 吨**（联合黄金并购） |
| 锂 | — | 2.5 → 12 → 27-32 万吨（**+371% 起**） |
| 弹性 | 铜价每 +5000 元/吨 → 归母 +12 亿 | 量价齐升的乘法效应 |

**成长性结论**：紫金是「全球找不出第二家」的万亿矿企还能两位数增产（铜 +11%/年、金 +13%/年）；洛钼铜增 ~6.5%/年、靠 KFM/TFM 扩产 + 黄金从 0 到 1。**紫金成长性更厚、更确定，洛钼弹性更集中、更周期。**

## 四、短中长期怎么看

| 周期 | 洛阳钼业 | 紫金矿业 | 共同逻辑 |
|---|---|---|---|
| **短期（1-3 月）** | 站上全部均线 + 放量，看回补 24-25 元缺口（1 月平台） | 反弹目标先看 37-40 元（3-5 月密集成交区） | 中报季（8 月底）业绩兑现 + 铜金维持高位 + 风格切换延续 → 估值修复行情 |
| **中期（3-12 月）** | 2026 全年 ~340 亿利润兑现，铜产量冲 80 万吨，黄金并表增厚 | 2026 ~844 亿利润，锂从 0 到 1 放量，巨龙二期达产 | 「戴维斯双击」：业绩 + 估值同步上修；前提是加息预期不再复活 |
| **长期（2-3 年）** | 2028 铜冲 100 万吨、黄金 20 吨，迈向全球前十铜企 | 2028 铜 150-160 万吨、金 130-140 吨，对标必和必拓/力拓估值 | 资源为王 + AI 算力电气化 + 央行购金的超级周期；周期成长股 |

**风险点（必须盯）**：

- **加息预期复活**（2-5 月就是这样杀的：美伊冲突→油价→CPI 3.8%/4.2%→加息→有色暴跌）
- **铜金回调**：铜在历史高位，技术性回踩 + 铝代铜替代 + 美国「库存堰塞湖」回流风险
- **海外政治**：刚果金暴利税/钴出口配额、塞尔维亚、巴新矿业政策（洛钼钴风险更大）
- **A 股风格再切回科技**（若 AI 叙事重新主导）

### 怎么用这个表

- **当前价 ≈ 中性情景**：也就是说，**现在的价格已经把「2026 业绩爆发」基本计价了**。再往上的空间，不来自「业绩超预期」（那已被预期），而是来自 **① 商品继续涨 ② 估值重新扩张（周期叙事回归） ③ 风格切换**。
- **谁更值**：
  - **求稳、求确定性** → **紫金**：forward PE 10.8x（比洛钼 12.8x 还便宜）、ROE 33%、金铜锂三驱动、机构目标价更分散向上（39-56）、洗盘更充分（6 月 PE 砸到 10.8x）。
  - **求弹性、博铜价** → **洛钼**：铜毛利占六成最纯，铜价每涨 5000 元归母 +12 亿；但波动更大、钴政策风险更高、净利率只有紫金一半。
- **现实建议**：两只都是**强周期股**，「业绩持续兑现但股价宽幅震荡」是常态。**别在 PE 分位 70%+ 追高，回调到均线（洛钼 18-19 / 紫金 30-32）分批更舒服**。8/5 刚放量启动，短线别追涨停，等回踩确认。

## 结语

这俩的基本面是 A 股周期股里最硬的（万亿紫金还能 +60% 利润增速、千亿洛钼净利两年从 23 亿到 340 亿），但**周期股最大的敌人永远是宏观（加息预期）**。把铜金价格和美 CPI 当作持仓的「心跳监护仪」——它们不拐头，故事就还在。
