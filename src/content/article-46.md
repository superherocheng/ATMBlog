# 6月科技大跌是终点还是中继？广发·国投·华福三份研报交叉验证

> 三份券商研报，发布于 2026 年 8 月 9–11 日，**共同指向同一个事件：6 月 23 日开始的 AI / 科技板块大调整，以及"调整之后买什么"**。但三者切入视角完全不同——广发看产业趋势、国投看历史复盘、华福给量化择时工具。把它们拼在一起，能还原出一幅远比单份报告完整的市场图景，也能用量化视角看清其中哪些结论稳健、哪些需要打折。

---

## 一、总览：三份报告的共同底色

| 报告 | 视角 | 核心问题 | 一句话结论 |
|---|---|---|---|
| **广发**·刘晨明/陈振威《谁将引领AI新叙事》 | 产业链 / 全球映射 | 6 月调整是趋势终结还是阶段出清？ | **不是终点，是阶段性顶部；主线仍在 AI，下一波靠 RSI** |
| **国投**·林荣雄/黄玮宗《每次高切低之后》 | 11 轮历史复盘 | 高切低之后主线会不会换？ | **高切低指数已到 30% 下沿→行情近尾声；70-80% 概率换主线，但强产业趋势下只换权重不换主线** |
| **华福**·李杨等《微盘股择时》 | 量化择时 | 微盘股何时进、何时退？ | **三段式择时（MA15 + 底部 + 顶部）年化 30.6% / 夏普 1.80；7 月 31 日已翻多** |

**关键共识**：三份报告对当下都偏 **constructive（逢低布局风险资产、AI 主线未破）**，同时都承认行情已从"无脑单边"进入"**高波动、高轮动、需基本面验证**"阶段。这条共识本身，比任何单份报告的细节都更值得记住。

## 二、广发《谁将引领 AI 新叙事》—— 产业趋势视角

### 1. 调整解剖：不是需求崩塌，是"拥挤 + 回报率重估"

6/23 调整由三股力量叠加触发：

- **交易松动**：高估值（KOSPI 9114、创业板 4359、费半 14634 均处高位）遇上韩国杠杆 ETF 监管收紧 → 融资平仓。6/25 苹果以存储涨价为由上调 Mac/iPad 售价，成为共识性卖出信号。
- **回报率被重估**：Coding 需求本身没萎缩（Cursor ARR 仍在升），但市场交易的是**二阶变化**——使用量虽增却未持续超预期，而算力投入仍快速上升。7 月初 Meta 称"AI agent 进展慢于预期、考虑出售多余算力"成为关键拐点。**Kimi K3（7/16 发布）作为国产模型进 Chatbot Arena 前 10**，进一步压低海外闭源厂商的定价权与护城河。
- **存储盛宴降温**：三星、SK 海力士业绩创新高但仍不及激进预期，DRAM 涨价最快阶段已过 + SK 海力士扩产过快（2027 折旧 + 降价双杀担忧）+ 长鑫存储上市募资 → 动摇"全球存储长期绝对短缺"的估值假设。

### 2. 企稳的三条新叙事

1. **从"惩罚 CapEx"到"奖励兑现"**：市场不再单纯罚云厂自由现金流恶化，转向看 CapEx 能否转化为收入 / 利润。微软、亚马逊（超预期最明显）7/29–8/7 分别反弹 28.0%、21.1%；Meta（营业利润低于预期、FCF 同比 -91%）反弹最弱。
2. **CapEx 再上修**：二季报后四大云 2026E CapEx 合计再 +250 亿美元，利好硬件链（芯片 / 通信 / 存储订单担忧缓解）。
3. **增速缺口仍在，模型商 + 新云能否接棒**：这是全报告最有量化含金量的部分。

### 3. 核心测算：CapEx 增速缺口与 RSI 接棒

四大云 CapEx 加权增速：**2025A 67% → 2026E 105% → 2027E 45% → 2028E 9%**（断崖式回落）。

模型商 + 新云（OpenAI Stargate ~7GW、AMD 6GW 协议；Anthropic 2GW；xAI 巨像集群 2027 CapEx 739 亿美元；Coreweave 等 Neocloud）按 GW × 单位投资强度（基础设施 8–12 美元/W + GPU 差异化）测算：

- 2027E 可新增 **~10GW 算力、中值 4609 亿美元 CapEx**（模型商 2698–3398 亿）
- 2028E 中值 **5252 亿美元**

**接棒测算的关键结论（报告自承"方向性正确、定量有待商榷"）**：

- 若只需维持 **2025A 的 67% 增速**：2028 缺口 5055 亿 < 模型商 + 新云 5252 亿 ✅ **能填补**
- 若要维持 **2026E 的 105% 增速**：2028 缺口 **19376 亿** ≫ 5252 亿 ❌ **远不够**

→ 这意味着 **RSI / 训练需求叙事只能支撑"回归常态增速"，无法支撑"继续加速"**。这是全报告最该被记住的数字边界——叙事可以乐观，但增速曲线不能。

### 4. 展望与监测

- **修复分化**：海外先行（美股半导体 → 云厂反弹、韩国去杠杆后高波筑底），**A 股仅小幅抬升**（缺乏同步盈利验证 + 增量资金）。
- **轮动路径**：硬件 → 云厂商 → 模型商 → 应用。关注即将上市的模型商（已出现收入增长 + 实质盈利迹象）。
- **三套监测框架**：AI 景气框架（13 指标）、美股泡沫框架（**实体投资仅相当 1994-95 中期扩张阶段→远未过热**；但情绪 / 估值已到 **1999-2000 水平**）、韩国风险框架（杠杆 ETF 去化 55%、强平压力低于 10 年均值 1σ，未现系统性流动性挤兑）。

## 三、国投《每次高切低之后》—— 历史复盘视角

### 1. 核心判断：高切低行情近尾声

- **A 股高切低指数**：6 月下旬触及区间高位 60%，现已回落至 **30%（历史底部区间）** → 本轮再均衡行情趋于尾声。
- **两种形态**：① 低位补涨（前后主线一致性较高）；② 高低普跌（前后主线一致性低）。
- **概率法则**：约 **70-80% 概率主线大换血，20-30% 概率延续**；即便延续，核心品种也会变。
- **铁律**：**景气和产业趋势是主线形成与延续的必要条件**——没有它，高切低后就是低位无序轮动或混沌空窗。

### 2. 十一轮复盘（2016.4–2026.3）浓缩

| 轮次 | 旧主线 → 过渡抗跌 → 新主线 | 切换程度 |
|---|---|---|
| 2016/4 | 消费金融 → 食饮 / 银行抗跌 → 低估值周期 / 成长(TMT + 军工) | 大切换 |
| 2017/8 | 供给侧周期 + 白马 → 仅食饮抗跌 → 顺周期消费 + 科技 | 大切换 |
| 2019/5 | 消费猪 + 白酒 + 计算机 → TMT / 消费抗跌 → TMT / 医药 / 消费 | 中度切换 |
| 2021/2 | 茅 + 宁抱团 → 公用 / 环保低位补涨 → **新能源延续** | **延续(例外1)** |
| 2021/11 | 新能源 + 资源 → 仅煤炭抗跌 → 超跌反弹后无主线(空窗 8.3 个月最长) | 完全切换 |
| 2023/7 | TMT/AI + 中特估 → 仅煤炭涨 → 高股息红利 | 完全切换 |
| 2024/7 | 高股息防御 → 银行 / 公用抗跌 → **924 后 AI 应用(政策驱动)** | 完全切换 |
| 2025/2 | AI 应用 + 机器人 → 农林牧渔 / 公用抗跌 → **AI 算力延续** | **延续(例外2)** |
| 2025/9 | AI 算力 + 新能源 + 有色 → 石油 / 银行 / 煤炭抗跌 → 军工 + AI 硬科技 | 浅切换(链内扩散) |
| 2026/3 | HALO 资源 + 红利 → 回调极短、仅通信 / 石油微涨 → AI 硬科技 | 高度切换 |

### 3. 最重要的洞察（与广发形成共振）

**两次"延续型"例外（2021 新能源、2025 AI）的共同机制：强产业趋势下，外部冲击只能扰乱节奏，不能置换主线**。2025/2 关税冲击造成的是"节奏中断而非产业逻辑破裂"，主线在 AI 链内由应用迁徙到算力硬件。

→ 国投用历史规律给出**定性答案**：当下 AI 产业趋势仍具黏性，高切低后**主线大概率延续而非换血**，与广发的"不是终点"殊途同归。但国投也警告：**反弹最持续的品种未必是此前下跌最多的品种**——核心品种会发生变化。

## 四、华福《微盘股择时》—— 量化择时视角

这是三份里**最可执行、也最该用批判眼光审视**的一份。

### 1. 微盘股的本质：是 size beta，不是 alpha

- Barra 归因：**市值因子暴露长期深度负值**，贡献了绝大部分超额收益；2021–2023 市值因子单边上行是微盘行情主因。Beta / 流动性 / 动量贡献偏弱。
- **"流动性不创造收益，但需要流动性支撑"**——流动性一收缩，即便基本面无变化也剧烈回撤。
- **非对称弹性**：牛市平均领涨 +66%，熊市平均跌 -25%。微盘牛市与小盘风格占优几乎完全重合。
- 结论：**绝大多数超额收益来自极小盘风格的 Beta 暴露，非个股 alpha**。

### 2. 四种指标角色（可解释决策链）

放弃综合打分，把因子分为四个**职责固定**的角色：

1. **启动确认（最高优先级）**：底部机制，可覆盖下行趋势的空仓信号提前入场。
2. **风险确认（次之）**：顶部机制，结构转弱时强制空仓，不等均线破位。
3. **趋势锚（兜底）**：MA15，常态仓位，不猜底猜顶。
4. **结构解释（不参与日频决策）**：两融 / 筹码 / 龙虎榜，仅用于复盘（披露滞后、事件稀疏）。

### 3. 基础均线 MA(15)：是回撤控制，不是收益增强

- 对 MA(5)–MA(20) 遍历，**MA(15) 最优**：年化 22.96%、波动 18.64%、夏普 1.23、MDD 17.65%（vs 买入持有 46.73%，回撤削减 60%+）。
- **但超额年化仅 1.36%、信息比率仅 0.06** → 这是**回撤控制工具，不是收益增强工具**。2019-2021 连续三年负超额，踏空与避险交替。

### 4. 底部增强：三重逻辑门

**普通底部**：超跌释放（60 日回撤 >10% + 距 MA15 偏离 >3% + RSI ≤45）→ 资金承接（flow_breadth ≥55% + 边际改善 ≥5% + 主力净流入 >0）→ 价格确认（突破前 3 日 / 5 日高点，大小盘风格过滤动态调门槛）。

**危机型底部**（专为 2024/2/8 设独立通道）：60 日回撤 ≥35% + ATR 较 5 日前升 ≥20% + 当日涨幅 ≥5%（无需等慢均线，首日强反转直接放行）。

参数筛选用**跨期木桶效应**（min(前段胜率, 后段胜率) 优先，防过拟合）。全样本 **16 次信号、15 日胜率 93.75%、年化 11.66%、期末净值 3.09**。

### 5. 顶部增强：高位 + 结构衰减 + 资金恶化

单指标都不稳定（扩散指数只覆盖 4/8 个顶部）。最优融合：**扩散指数曾 ≥0.85 + 5 日内回落 ≥0.05 + 资金流广度 / 主力净流入恶化 → 空仓 10 日**。全样本：年化 20.52%、夏普 0.81。**注意：顶部增强几乎没有改善绝对收益（20.52 vs B&H 20.31），主要压低波动**。

### 6. 三段式综合策略（最终成果）

- **年化 30.60%、夏普 1.80、MDD 20.40%、Calmar 1.50**（vs B&H 20.31% / 46.73%）。
- **当前信号：2026 年 7 月 31 日翻多**（普通底部确认：超跌记忆 + 价格突破前 5 日高点 + 资金广度 73.79% + 主力净流入转正 1.38%）。

## 五、三者交叉验证：一幅完整的市场图景

把三份拼起来，逻辑链是自洽的：

1. **广发**确认 AI 产业趋势未破（CapEx 仍在加码、云厂财报验证），只是进入"需基本面兑现"的高波阶段；
2. **国投**用历史规律背书：强产业趋势下高切低只换权重不换主线，AI 主线大概率延续；
3. **华福**在微盘这个高弹性品种上给出具体入场时点——**7 月 31 日翻多**，恰好与广发"7 月末企稳"、国投"高切低指数回落至 30% 下沿"落在同一时间窗口。

> 三份报告在不同维度上**共同指向：8 月初是本轮调整后的逢低布局窗口，AI / 成长主线延续**。差异在于广发更强调"硬件 → 云 → 模型 → 应用"的轮动节奏（暗示别只盯着硬件），华福给的是微盘的纯择时信号（不看主线只看量价 / 资金 / 扩散结构）。

## 六、量化视角的批判性审视（值得保留 vs 需打折）

这是最该慢下来读的一节。研报的结论不能照单全收，要分清哪些是稳健的结构性洞察、哪些是样本不足的脆弱统计。

| 报告 | 稳健可信的部分 | 需要打折 / 警惕的部分 |
|---|---|---|
| **广发** | 三条企稳叙事的事实基础（云厂财报、CapEx 上修）扎实；泡沫框架（实体投资仅 1994-95 阶段）客观 | **RSI 叙事偏前瞻投机**；CapEx 缺口数学本身证明 RSI 只能撑"回归常态增速"而非"继续加速"——报告自承"定量有待商榷" |
| **国投** | "强产业趋势 → 只换权重不换主线"的机制洞察深刻且可迁移 | 11 个样本的定性复盘，"70-80% 换主线"是粗略启发式；无法量化，只能作背景判断 |
| **华福** | MA15 择时 = 回撤控制（夏普 1.23、MDD 砍 60%）这点稳健，且与"择时是风险层非 alpha 层"的普遍规律一致 | **①样本极小**：16 信号 / 10 年，93.75% = 15/16 胜，统计脆弱；**②顶部参数平台窄**：0.85/0.05 最优但 0.80、0.90 明显变差——报告自承过拟合风险；**③收益高度依赖单一事件**：2024 年 97.70%（超额 79.10%）几乎全来自准确捕捉 2 月量化踩踏 V 型反转，去掉这一年策略对 B&H 的超额信息比率（0.32）会很平庸；**④超额最大回撤仍达 40.78%** |

**一句话总结**：华福的策略价值主要在"**规避微盘的尾部流动性回撤**"（如 2024 初那种），而非持续创造超额。这与一个反复被验证的结论同源——**择时是风险控制层，不是 alpha 层**。任何把择时策略的样本内年化收益当成稳定 alpha 的读法，都会在样本外付出代价。

## 七、可迁移的方法论启示

抛开具体结论，这三份报告里有几个**可复用的研究框架**值得沉淀：

1. **扩散因子（diffusion index，站上 MA15 个股占比）**：华福用它做"高位衰减"识别顶部，本质是市场广度 / 参与度的横截面信号。它回答"价格上涨是由谁驱动的"——指数创新高但扩散指数回落，说明上涨越来越集中在少数权重股，内部结构变脆弱。这类**截面宽度因子**对顶部择时可能有独立增量，值得纳入因子库。

2. **三重逻辑门架构**（位置测度 + 资金测度 + 价格测度，而非单一超跌）比单纯 RSI / MA 偏离更稳健：位置回答"跌得够不够深"，资金回答"抛压是否缓解"，价格回答"反弹是否已开始"。三者共振才入场，可显著降低误触发。

3. **危机型底部独立通道**（极端回撤 + ATR 扩张 + 首日强反转放行，不等慢均线）是针对 2024 初量化踩踏这类**流动性黑天鹅**的合理工程化处理——普通底部的渐进确认不适用于连续下跌后的首日强反转。回测引擎若不区分"普通底"和"危机底"，会系统性错过最有价值的反弹段。

4. **广发的 CapEx 缺口算术**是一个可复用的"产业趋势持续性"定量框架：用"维持历史增速所需增量 vs 已知项目可提供增量"做剪刀差，比定性判断"趋势在不在"严谨得多。同样的框架可迁移到任何资本开支驱动的产业链（新能源、半导体设备、电力算电等）。
